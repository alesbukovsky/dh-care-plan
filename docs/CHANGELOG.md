# Changelog

This document captures only changes affecting user experience and tool usage. It does not list versions that carry only
internal changes.

## 0.6.0 (2026-10-13)

- Human need statements in the template are sorted by priority (lowest number first, controlled via configuration).

## 0.5.5 (2026-10-09)

- Goal intervention field changed to a resizable multi-line text area.

## 0.5.4 (2026-09-18)

- New icons set applied.

## 0.5.3 (2026-09-16)

- Shape of the highlight color selectors in the case study changed to square.
- Application in an active tab checks automatically for updates.

## 0.5.2 (2026-09-15)

- Banner notification you when a new version of the application is available.

## 0.5.0 (2026-09-14)

- User guide added, linked from the application.
- Medications and medical conditions are edited together in a single list.
- Date of birth is now a free-text field with an optional age calculator available.
- BMI field has an optional calculator based on height and weight.

## 0.4.1 (2026-09-11)

- Soft validation warns about a missing need priority.
- Vitals are a single list in the template data.
- Met / unmet need flag is no longer inverted compared to the rest of the plan.

## 0.4.0 (2026-09-10)

- Added medical history interpretations (conditions) in the plan.
- Added highlighting marker in the case study text.
- Most text fields are now resizable text areas.
- Past visits with vitals are replaced by vitals records that may be undated.
- Fixed validation error dialog hidden under the file selection dialog.

## 0.2.1 (2026-09-02)

- Fixed missing "met" label mapping in the configuration dialog.

## 0.2.0 (2026-08-31)

- Human needs now carry priority and rationale.
- Removed significance field from the subjective data.
- Fixed divider appearing after the last assessment record.

## 0.1.0 (2026-08-04)

- Initial release with full plan editor, configuration and plan generator.
